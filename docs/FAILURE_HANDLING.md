# 故障处理说明

| 事件 | 系统动作 | 是否可自动重试 |
| --- | --- | --- |
| 参数或 Schema 不合法 | Preview 阶段拒绝 | 否，需修正输入 |
| Target 二次确认不一致 | 不创建预派发记录 | 否 |
| Snapshot 过期 | 标记 `EXPIRED` | 否，需新建 Preview |
| Provider 明确拒绝 | 标记 `FAILED` | 否 |
| 写入结果不确定 | 标记 `UNKNOWN` | 否，禁止重复写 |
| 只读查询瞬态失败 | 有界重试 | 是，仅查询 |
| Read-back 不一致 | 标记 `FAILED` | 否，需人工调查 |
| 进程崩溃 | 从 SQLite 读取状态 | 不重新派发 |

该策略强调“宁可冻结、也不重复外部写入”。
