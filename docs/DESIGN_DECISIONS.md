# 设计决策

## 为什么 UNKNOWN 不重试

当网络在写入后断开时，客户端不知道外部系统是否已接收请求。自动重试可能产生两次外部副作用，因此本实现将其标为 `UNKNOWN`；只有在存在 Provider Task ID 时才允许只读查询。

## 为什么 Preview 必须失效

预览确认的是一个时间点的输入。长期停留的页面可能对应过期素材、权限或目标，故在外部写入前检查 TTL；过期时拒绝执行并要求新建请求。

## 为什么审计 append-only

执行前后的证据必须可追溯。状态表保存当前事实，审计表记录每次决定；示例不允许“回写历史”以掩盖失败或不确定状态。

## 为什么 Mock 仍有价值

Mock 不代表生产服务，但可稳定注入明确失败、未知写入、瞬态读失败和回读不一致，验证系统在风险边界的行为。
